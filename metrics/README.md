# Quality metrics

This directory is the measurable baseline for hdf5-agent. CI regenerates
`current.json` on every pull request so later changes can be compared against
`baseline.json` (the May 2026 MVP) and against the previous PR.

## Files

| File | Meaning |
|------|---------|
| `baseline.json` | Frozen snapshot of `main` before this professionalization |
| `current.json` | Generated by `go run ./cmd/metrics` (local and CI) |

## Collect

```bash
make test          # writes coverage.out
make metrics       # writes metrics/current.json and prints a delta vs baseline
```

CI fails if tests fail, if Python files reappear, or if there are zero Go tests.
Coverage going up or down is reported as a delta, not a silent skip.
